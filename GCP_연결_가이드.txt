🚀 GCP 서버 연결 및 업로드 가이드
=====================================

📋 사전 준비사항
----------------
1. GCP 계정 및 프로젝트 설정 완료
2. VM 인스턴스 생성 (GCP_설정_가이드.txt 참조)
3. SSH 키 생성 및 등록
4. 방화벽 규칙 설정 (포트 22, 8000)

🔑 SSH 키 생성 (Windows)
------------------------
1. PowerShell에서 SSH 키 생성:
   ssh-keygen -t rsa -b 4096 -C "your-email@example.com"

2. 기본 위치: C:\Users\[사용자명]\.ssh\id_rsa

3. GCP 콘솔에서 SSH 키 등록:
   - Compute Engine > 메타데이터 > SSH 키
   - id_rsa.pub 파일 내용 복사하여 등록

📤 방법 1: 자동 업로드 스크립트 사용
-----------------------------------
1. PowerShell에서 스크립트 실행:
   .\upload_to_gcp.ps1 -ServerIP "34.123.45.67" -Username "your-username"

2. 스크립트가 자동으로:
   - 필수 파일 확인
   - 서버 연결 테스트
   - 전체 프로젝트 업로드
   - 환경 설정 (가상환경, 의존성 설치)

📤 방법 2: 수동 업로드
---------------------
1. SCP 명령어로 파일 전송:
   scp -r C:\pigg4949\HairSwap [username]@[server-ip]:/home/[username]/

2. SSH로 서버 접속:
   ssh [username]@[server-ip]

3. 프로젝트 디렉토리로 이동:
   cd /home/[username]/HairSwap

4. 환경 설정:
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt

📤 방법 3: Git 사용 (권장)
-------------------------
1. GitHub/GitLab에 저장소 생성

2. 로컬에서 Git 초기화:
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin [repository-url]
   git push -u origin main

3. GCP 서버에서 클론:
   git clone [repository-url]
   cd HairSwap

🔧 서버에서 서비스 실행
-----------------------
1. SSH로 서버 접속:
   ssh [username]@[server-ip]

2. 프로젝트 디렉토리로 이동:
   cd /home/[username]/HairSwap

3. 가상환경 활성화:
   source venv/bin/activate

4. 서비스 실행:
   # 방법 A: 직접 실행
   python app.py
   
   # 방법 B: 스크립트 사용
   bash run_service.sh
   
   # 방법 C: 백그라운드 실행
   nohup python app.py > app.log 2>&1 &

5. 서비스 상태 확인:
   curl http://localhost:8000/health

🌐 웹 인터페이스 접속
---------------------
브라우저에서 다음 URL로 접속:
http://[server-ip]:8000

예시: http://34.123.45.67:8000

🔍 문제 해결
-----------
1. 연결 실패:
   - 서버 IP 주소 확인
   - SSH 키 등록 확인
   - 방화벽 규칙 확인

2. 파일 업로드 실패:
   - 디스크 공간 확인
   - 권한 문제 확인
   - 네트워크 연결 확인

3. 서비스 실행 실패:
   - Python 버전 확인 (3.8+)
   - 의존성 설치 확인
   - GPU 드라이버 확인

📞 지원
-------
문제 발생 시 다음 정보를 확인:
- 서버 IP 주소
- 오류 메시지
- 로그 파일 내용 (app.log)
