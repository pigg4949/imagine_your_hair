🔄 GCP 서버 ↔ 로컬 동기화 가이드
=====================================

📋 동기화 방법 개요
-------------------
1. Git을 통한 동기화 (가장 권장)
2. SCP를 통한 파일 전송
3. rsync를 통한 실시간 동기화
4. 자동화 스크립트 사용

🚀 방법 1: Git을 통한 동기화 (가장 권장)
----------------------------------------
가장 안전하고 효율적인 방법입니다.

**GCP 서버에서 작업 후:**
```bash
# 서버에서 변경사항 커밋
cd /home/username/HairSwap
git add .
git commit -m "서버에서 작업한 내용"
git push origin dev
```

**로컬에서 동기화:**
```bash
# 로컬에서 최신 변경사항 가져오기
git pull origin dev
```

**장점:**
- 버전 관리 가능
- 충돌 해결 기능
- 안전한 백업
- 협업 가능

📤 방법 2: SCP를 통한 파일 전송
-------------------------------
특정 파일이나 폴더만 전송할 때 유용합니다.

**전체 프로젝트 동기화:**
```bash
# 서버 → 로컬
scp -r username@server-ip:/home/username/HairSwap .

# 특정 폴더만 동기화
scp -r username@server-ip:/home/username/HairSwap/outputs .
scp -r username@server-ip:/home/username/HairSwap/logs .
```

**특정 파일만 동기화:**
```bash
# 설정 파일만
scp username@server-ip:/home/username/HairSwap/app.py .
scp username@server-ip:/home/username/HairSwap/requirements.txt .

# 로그 파일만
scp username@server-ip:/home/username/HairSwap/app.log .
```

🔄 방법 3: rsync를 통한 실시간 동기화
-----------------------------------
변경된 파일만 효율적으로 동기화합니다.

**설치 (Windows):**
```bash
# WSL 또는 Git Bash에서 사용
# 또는 rsync for Windows 설치
```

**사용법:**
```bash
# 전체 동기화 (Git 제외)
rsync -avz --exclude='.git' --exclude='venv' --exclude='__pycache__' username@server-ip:/home/username/HairSwap/ .

# 특정 폴더만 동기화
rsync -avz username@server-ip:/home/username/HairSwap/outputs/ ./outputs/
rsync -avz username@server-ip:/home/username/HairSwap/logs/ ./logs/

# 삭제된 파일도 동기화
rsync -avz --delete username@server-ip:/home/username/HairSwap/ .
```

🤖 방법 4: 자동화 스크립트 사용
-------------------------------
제공된 PowerShell 스크립트를 사용합니다.

**전체 동기화:**
```powershell
.\sync_from_gcp.ps1 -ServerIP "34.123.45.67" -Username "your-username" -SyncType "all"
```

**출력 파일만 동기화:**
```powershell
.\sync_from_gcp.ps1 -ServerIP "34.123.45.67" -Username "your-username" -SyncType "outputs"
```

**로그 파일만 동기화:**
```powershell
.\sync_from_gcp.ps1 -ServerIP "34.123.45.67" -Username "your-username" -SyncType "logs"
```

**설정 파일만 동기화:**
```powershell
.\sync_from_gcp.ps1 -ServerIP "34.123.45.67" -Username "your-username" -SyncType "config"
```

📁 동기화 대상별 가이드
-----------------------

### 1. **출력 파일 동기화**
```bash
# 생성된 이미지 결과물
scp -r username@server-ip:/home/username/HairSwap/outputs/ ./outputs/

# 또는 스크립트 사용
.\sync_from_gcp.ps1 -ServerIP "server-ip" -Username "username" -SyncType "outputs"
```

### 2. **로그 파일 동기화**
```bash
# 서비스 로그
scp username@server-ip:/home/username/HairSwap/app.log .
scp username@server-ip:/home/username/HairSwap/*.log ./logs/

# 또는 스크립트 사용
.\sync_from_gcp.ps1 -ServerIP "server-ip" -Username "username" -SyncType "logs"
```

### 3. **설정 파일 동기화**
```bash
# 코드 변경사항
scp username@server-ip:/home/username/HairSwap/*.py .
scp username@server-ip:/home/username/HairSwap/requirements.txt .
scp -r username@server-ip:/home/username/HairSwap/templates/ ./templates/

# 또는 스크립트 사용
.\sync_from_gcp.ps1 -ServerIP "server-ip" -Username "username" -SyncType "config"
```

### 4. **전체 프로젝트 동기화**
```bash
# Git 제외하고 전체 동기화
rsync -avz --exclude='.git' --exclude='venv' --exclude='__pycache__' username@server-ip:/home/username/HairSwap/ .

# 또는 스크립트 사용
.\sync_from_gcp.ps1 -ServerIP "server-ip" -Username "username" -SyncType "all"
```

⏰ 자동 동기화 설정
------------------

### 1. **Windows 작업 스케줄러 사용**
```powershell
# 매일 특정 시간에 자동 동기화
schtasks /create /tn "HairSwap Sync" /tr "powershell -File C:\pigg4949\HairSwap\sync_from_gcp.ps1 -ServerIP 'server-ip' -Username 'username' -SyncType 'outputs'" /sc daily /st 18:00
```

### 2. **PowerShell 스크립트 루프**
```powershell
# 5분마다 자동 동기화
while ($true) {
    .\sync_from_gcp.ps1 -ServerIP "server-ip" -Username "username" -SyncType "outputs"
    Start-Sleep -Seconds 300
}
```

```bash

```


✅ 권장 워크플로우
-----------------
1. **개발**: 로컬에서 코드 작성
2. **업로드**: Git push로 서버에 배포
3. **실행**: 서버에서 서비스 실행
4. **결과 확인**: outputs 폴더 동기화
5. **분석**: 로컬에서 결과 분석
6. **개선**: 코드 수정 후 반복

이 워크플로우를 통해 효율적으로 개발과 서비스 운영을 병행할 수 있습니다!
