💻 Cursor에서 GCP 서버 원격 개발 가이드
========================================

🚀 VS Code Remote Development 설정
----------------------------------

### 1단계: Cursor에서 Remote-SSH 확장 설치

1. **Cursor 열기**
2. **확장 마켓플레이스** (Ctrl+Shift+X)
3. **"Remote - SSH"** 검색 및 설치
4. **"Remote - SSH: Editing Configuration Files"** 설치

### 2단계: SSH 설정 파일 생성

**Cursor에서:**
1. **Ctrl+Shift+P** → "Remote-SSH: Open SSH Configuration File"
2. **~/.ssh/config** 선택
3. 다음 설정 추가:

```
Host gcp-hairswap
    HostName YOUR_SERVER_IP
    User YOUR_USERNAME
    IdentityFile ~/.ssh/id_rsa
    Port 22
    Compression yes
    ServerAliveInterval 60
    ServerAliveCountMax 3
```

### 3단계: 서버에 연결

1. **Ctrl+Shift+P** → "Remote-SSH: Connect to Host"
2. **gcp-hairswap** 선택
3. **새 창에서 열기** 선택
4. **서버의 프로젝트 폴더 열기**: `/home/username/HairSwap`

### 4단계: 개발 환경 설정

**서버에서 Python 확장 설치:**
1. **확장 마켓플레이스**에서 "Python" 검색
2. **Microsoft Python 확장** 설치
3. **Python 인터프리터 선택**: `/home/username/HairSwap/venv/bin/python`

🎯 Cursor AI 기능 활용
----------------------

### 1. **코드 자동 완성 및 제안**
- **Ctrl+Space**: AI 제안
- **Tab**: 제안 수락
- **Ctrl+Enter**: 전체 라인 완성

### 2. **코드 설명 및 리팩토링**
- **코드 선택** → **우클릭** → **"Explain Code"**
- **코드 선택** → **우클릭** → **"Refactor Code"**

### 3. **버그 찾기 및 수정**
- **Ctrl+Shift+P** → **"Cursor: Find and Fix Bugs"**
- **파일 전체 분석** → **자동 버그 수정 제안**

### 4. **AI와 대화**
- **Ctrl+L**: Cursor AI 채팅 열기
- **코드 관련 질문** → **실시간 답변**

### 5. **자동 테스트 생성**
- **함수 선택** → **우클릭** → **"Generate Tests"**
- **AI가 자동으로 테스트 코드 생성**
