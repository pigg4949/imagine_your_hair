# 💇‍♀️ 헤어스타일 DreamBooth 학습 가이드

## 📊 데이터 요구사항

### 🎯 **이상적인 데이터셋 구성**

#### 1. **데이터 수량**
- **최소**: 10-15장의 고품질 이미지
- **권장**: 20-30장의 다양한 각도 이미지
- **최적**: 50-100장의 체계적인 이미지

#### 2. **이미지 품질 기준**
```
✅ 좋은 예시:
- 해상도: 512x512 이상 (1024x1024 권장)
- 선명도: 얼굴과 헤어가 명확하게 보임
- 조명: 균등한 조명, 그림자 최소화
- 각도: 정면, 측면, 45도 등 다양한 각도
- 표정: 자연스러운 표정
- 배경: 단순한 배경 (흰색/회색 벽)

❌ 피해야 할 예시:
- 흐릿한 이미지
- 극단적인 조명 (역광, 과도한 그림자)
- 복잡한 배경
- 극단적인 표정
- 너무 작은 해상도
```

#### 3. **헤어스타일 다양성**
```
필수 포함 각도:
├── 정면 (3-5장)
├── 측면 (좌/우 각각 2-3장)
├── 45도 (좌/우 각각 2-3장)
├── 후면 (1-2장)
└── 미세한 각도 변화 (5-10장)
```

## 🎨 **헤어스타일별 특화 데이터**

### 1. **긴 머리 (Long Hair)**
```
데이터 구성:
├── 정면: 5장 (머리카락이 어깨에 닿는 모습)
├── 측면: 4장 (머리카락의 흐름이 보이는 각도)
├── 후면: 2장 (머리카락의 전체적인 모양)
└── 액션: 3장 (바람에 날리는 모습, 머리카락을 만지는 모습)
```

### 2. **단발 (Short Hair)**
```
데이터 구성:
├── 정면: 5장 (단발의 끝부분이 명확히 보임)
├── 측면: 4장 (단발의 레이어와 볼륨)
├── 후면: 2장 (단발의 전체적인 실루엣)
└── 스타일링: 3장 (다양한 스타일링)
```

### 3. **곱슬머리 (Curly Hair)**
```
데이터 구성:
├── 정면: 5장 (곱슬의 패턴이 명확히 보임)
├── 측면: 4장 (곱슬의 볼륨과 질감)
├── 후면: 2장 (곱슬의 전체적인 모양)
└── 자연스러운 상태: 3장 (스타일링하지 않은 자연스러운 곱슬)
```

## 🔧 **학습 파라미터 설정**

### 1. **기본 학습 설정**
```python
# 권장 학습 파라미터
learning_rate = 1e-6          # 낮은 학습률로 안정적 학습
max_train_steps = 1000        # 헤어스타일 특성에 따라 조정
train_batch_size = 1          # 메모리 효율성
gradient_accumulation_steps = 4  # 효과적인 배치 크기
```

### 2. **헤어스타일별 최적 설정**

#### **긴 머리**
```python
learning_rate = 1e-6
max_train_steps = 1200        # 긴 머리의 복잡한 패턴 학습
instance_prompt = "a photo of hst person with long flowing hair"
```

#### **단발**
```python
learning_rate = 1e-6
max_train_steps = 800         # 단발은 상대적으로 단순
instance_prompt = "a photo of hst person with short bob hair"
```

#### **곱슬머리**
```python
learning_rate = 5e-7          # 더 낮은 학습률 (복잡한 질감)
max_train_steps = 1500        # 곱슬 패턴 학습에 더 많은 스텝
instance_prompt = "a photo of hst person with curly natural hair"
```
